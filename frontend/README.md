# Frontend

`theme/againbuy/` contains the installable mobile-first WooCommerce theme. `tests/` contains CLI integration tests and is not served by WordPress.

Planned pages include home, category, search, product, cart, checkout, account, order history, payment retry, tracking and policy pages. Product pages will include category-based recommendations and administrator-pinned suggestions.

The theme uses WooCommerce's server-owned cart, checkout, stock and order flow. Product and order content must be entered by authorized staff; no sample catalog is deployed.
